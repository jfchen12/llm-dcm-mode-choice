# Evaluation examples

For each dataset:

- `*_evaluation_labels.csv`: synthetic labels for the 20 target trips.
- `*_prediction_template.csv`: matching trip IDs with a blank `predicted_mode` column. Fill this column before evaluation; blank entries are rejected.
- `*_mock_predictions.csv`: **mock outputs**, produced by the fastest-available-mode rule. These are not generated by an LLM and are not fitted DCM predictions.

The label file is supplied to the evaluator, not to the model. Keep it separate from the generated chat messages. Do not copy synthetic target labels into the prediction template to present them as model outputs.

Prediction codes differ between datasets. See the mode-code table in the root README. Use `-1` for an answer that cannot be parsed into a valid mode. The evaluator retains these failures in the sample denominator.

Actual generated responses are not bundled in this initial repository. The `prompts/` directory contains readable prompts and JSONL chat messages, not model responses.
